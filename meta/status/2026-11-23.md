# 2026-11-23: /slnc/ added

**Changed.** `aviary.herebox.org/slnc/` now serves the Silver Lake NC dashboard (311 requests, transit map, key
streets) by proxying its GitHub Pages site, `here.github.io/lax-slnc-transpo`, from the Worker's `fetch` handler
(`worker/index.js`; `run_worker_first` in `wrangler.jsonc`). `/slnc` redirects to `/slnc/`.

**Running.** The collectors are untouched. The dashboard's own repo refreshes its data daily.

**Next.** If GitHub Pages ever goes away, copy that site into `site/` and build it into `_site/slnc/` instead.

**Fixed.** `/slnc/transit` (no trailing slash) failed to load its data: the Worker followed GitHub Pages' redirect, so the page sat at the wrong URL. Redirects are now passed back to the browser.

# Meta: session status

Short status notes for agent sessions, so the next session (human or agent) can pick up quickly.

- One file per working session or day: `status/YYYY-MM-DD.md`, newest last.
- Under 1,000 characters each: what changed, what is running, what is next. Detail belongs in `docs/ROADMAP.md`
  (open work) and `AGENTS.md` (how the system works).
- Write it at the end of the session, after the roadmap is updated.
